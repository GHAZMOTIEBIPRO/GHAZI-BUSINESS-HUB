# نشر مجاني خطوة بخطوة (رابط HTTPS عام دون تكلفة)

المكوّنات المجانية: **GitHub** (كود خاص + CI) · **Neon** (PostgreSQL دائمة) · **Render** (الموقع) · **Brevo** (بريد عبر HTTPS API، 300 رسالة/يوم).
تحقق من صفحات الأسعار قبل التسجيل؛ الشروط قد تتغير.

> حدود المجاني: خادم Render ينام بعد ~15 دقيقة دون زيارات (أول زيارة بعدها ~دقيقة)، ويمنع منافذ SMTP؛ لذلك البريد عبر HTTPS API فقط.

## 0) قبل أي شيء
- اجعل المستودع **خاصًا** (Settings ← Danger Zone ← Change visibility). المستودع يحوي ملفات Excel المدفوعة.
- لا تضع مفاتيح أو كلمات مرور في المستودع؛ كلها متغيرات في Render.

## 1) Neon
neon.tech ← New Project ← انسخ Connection string (`postgresql://...?sslmode=require`).

## 2) Brevo
brevo.com ← Senders ← أضف بريد المرسل وأكّده ← SMTP & API ← API Keys ← أنشئ مفتاحًا.

## 3) Render
render.com (دخول بحساب GitHub، وامنح Render الوصول للمستودع الخاص) ← New ← **Blueprint** ← المستودع (يقرأ `render.yaml`، خطة free). أدخل:
- `HUB_DATABASE_URL` = رابط Neon
- `HUB_BASE_URL` = رابط الخدمة (مثل `https://ghazi-business-hub.onrender.com`)
- `HUB_MAIL_API_KEY` = مفتاح Brevo، `HUB_MAIL_FROM` = البريد المؤكد في Brevo
- `HUB_SETUP_TOKEN` يولَّد تلقائيًا (انسخه من لوحة Render).

## 4) حساب الإدارة الأول (مرة واحدة)
1. افتح `https://<رابطك>/setup` وأدخل رمز الإعداد وبريدًا **جديدًا** للإدارة (لا يمكن ترقية حساب موجود).
2. أكّد البريد من الرسالة الواردة، ثم فعّل **التحقق بخطوتين** (إلزامي).
3. احذف `HUB_SETUP_TOKEN` من Render. الصفحة تُغلق تلقائيًا بعد إنشاء أول مدير على أي حال.

## 5) الجدولة (اختياري)
في GitHub: Variable `HUB_BASE_URL` وSecret `HUB_JOBS_TOKEN` (نفس قيمة Render) ← يعمل `radar-refresh` كل ساعة.

## ما يبقى مقفلًا عمدًا
- `HUB_ENV=staging`: الدفع التجريبي لفريق المنصة فقط؛ المدفوعات الحقيقية مغلقة.
- لا بيانات تجريبية على الرابط العام؛ الرادار فارغ بصدق حتى تُدخل فرص موثقة.
- أوصاف الفرص من مصادر غير مرخّصة لا تُعرض؛ الرابط والحقائق فقط.

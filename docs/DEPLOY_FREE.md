# نشر مجاني خطوة بخطوة (رابط عام دون أي تكلفة)

المكوّنات المجانية: **GitHub** (الكود + CI + الجدولة) · **Neon** (قاعدة PostgreSQL دائمة) · **Render** (تشغيل الموقع).
لا يحتاج أي منها بطاقة دفع في الباقة المجانية وقت كتابة هذا الدليل — تحقق من صفحة الأسعار قبل التسجيل لأن الشروط قد تتغير.

> حدود المجاني: خادم Render المجاني ينام بعد نحو 15 دقيقة دون زيارات، وأول زيارة بعدها تستغرق قرابة دقيقة. مناسب للتجربة والعرض، وليس للإطلاق التجاري.

## 1) GitHub (دقيقتان) — يقوم به المالك
1. أنشئ مستودعًا فارغًا خاصًا باسم `GHAZI-BUSINESS-HUB` (دون README).
2. أخبر Claude ليرفع الكود ويشغّل CI ويفتح طلب دمج للمراجعة.

## 2) Neon — قاعدة البيانات
1. سجّل في neon.tech ← New Project ← المنطقة الأقرب (مثل Frankfurt).
2. انسخ **Connection string** (يبدأ بـ `postgresql://...?sslmode=require`).

## 3) Render — الموقع
1. سجّل في render.com بحساب GitHub ← New ← **Blueprint** ← اختر المستودع؛ سيقرأ `render.yaml` (خطة free).
2. عند الطلب أدخل:
   - `HUB_DATABASE_URL` = رابط Neon.
   - `HUB_BASE_URL` = رابط Render الذي سيظهر (مثل `https://ghazi-business-hub.onrender.com`).
   - `HUB_BOOTSTRAP_ADMIN_EMAIL` و`HUB_BOOTSTRAP_ADMIN_PASSWORD` (14 حرفًا على الأقل) لإنشاء حساب المدير الأول.
3. بعد النشر: ادخل بحساب المدير ← فعّل **التحقق بخطوتين** (إلزامي) ← احذف متغيري BOOTSTRAP من Render.

## 4) الجدولة المجانية (اختياري)
في إعدادات المستودع على GitHub:
- Variables: `HUB_BASE_URL` = رابط الموقع.
- Secrets: `HUB_JOBS_TOKEN` = نفس القيمة المولدة في Render.
سير العمل `radar-refresh` يستدعي التحديث كل ساعة (ويوقظ الخادم النائم).

## 5) البريد (اختياري، مجاني)
خطة SMTP مجانية (مثل Brevo) ثم في Render: `HUB_SMTP_HOST`, `HUB_SMTP_PORT=587`, `HUB_SMTP_USER`, `HUB_SMTP_PASSWORD`, `HUB_SMTP_FROM`.
بدونه تبقى رسائل الاستعادة والتنبيهات في صندوق الصادر ولا تُرسل.

## ما يكون مقفلًا عمدًا على الرابط العام
- `HUB_ENV=staging`: **الدفع التجريبي لفريق المنصة فقط**؛ الزوار لا يستطيعون «شراء» الملفات المدفوعة مجانًا.
- لا بيانات تجريبية: الرادار يعرض حالة فارغة صادقة حتى يُدخل المراجعون فرصًا موثقة.
- المدفوعات الحقيقية مغلقة (`HUB_PAYMENTS_LIVE_ENABLED=false`).
